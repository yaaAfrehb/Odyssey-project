## Challenges
Some things that were challenging:
1. Setting the buttons/ map markers for every place
2. Moving said map markers/ buttons into the correct spot (they kept on moving. i hated that)
3. Adding the popups
4. Javascript(just in general)

## Purpose
To look and interact with a really cool, custom-made map and learn a little about how a centuries old story can still connect to us today.

## How to Install
### Option 1:
Install Git on your laptop
Run this command in your laptop's bulit in terminal (or **Command Prompt**/ **Powershell** for Windows):

```bash
git clone https://github.com/yaaAfrehb/Odyssey-project.git
```
### Option 2:
If you don't want to use Git and the terminal:
1. Click on the Code button on the top of this repository page.
2. Click **Download ZIP**
3. Extract/ unzip the downloaded folder onto your computer.

Once you do one of the two, the files should be on your laptop. If you want to edit or run the code by yourself, you can open it on a code editor like VS Code. You can also open it by clicking the 'index.html' and pressing enter or double-clicking it!
