## Challenges
Some things that were challenging:
1. Setting the buttons/ map markers for every place
2. Moving said map markers/ buttons into the correct spot (they kept on moving. i hated that)
3. Adding the popups
4. Javascript(just general)

## Use
To look and interact with a really cool, custom-made map and learn a little about how a centuries old story can still connect to us today.

## Installation 🔧
If you want to run and view this on your device you have to:
1. **Clone the repository:**
    ```bash
   git clone https://github.com/yaaAfrehb/Odyssey-project.git
    ```
2. **Navigate to the project folder:**
   ```bash
   cd Odyssey project
   ```
3.  **Open the site:**
   Double-click the `index.html` file, or right-click it and select **Open with [Your Browser]**.
